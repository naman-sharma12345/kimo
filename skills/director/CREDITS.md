## Deliberate differences

- Physical camera language stays a contract; it is never silently replaced with a flat transform.
- Provider features require independently verified evidence; search excerpts and capability tables are not execution authority.
- Repeated coverage is a warning, not an automatic failure: intentional repetition is a legitimate edit choice.
- Non-default duration needs a reason. Short tracks and constrained providers do not lose their tail.
- The validator rejects malformed JSON shapes, non-finite numbers, unknown fields, invalid enums and path collisions without crashing.
- Repairs and paid generation are never automatic. Every output is an editable plan or transparent primitive batch.
- This is documentation plus agent-side Python tooling, not a new Rust MCP endpoint.
